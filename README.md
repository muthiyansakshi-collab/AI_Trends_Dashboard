📌 Overview

AI Trends Dashboard is a Python-based application that automates trend analytics using AI-related news data and Gemini LLM APIs.

---

🚀 Features

- Fetch AI news data
- Analyze trending keywords
- Generate CSV reports
- LLM-based summaries using Gemini API
- Modular code architecture
- Automated trend analytics pipeline

---

🛠 Technologies Used

- Python
- Pandas
- Gemini API
- LLMs
- CSV Processing
- Modular Programming
